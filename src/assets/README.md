# Images du site

Déposer ici les images à optimiser par Astro (portrait, captures de projets).

- Portrait : ajouter le fichier (ex. `portrait.jpg`, idéalement ≥ 1120 × 1360 px, format 4:5)
  puis renseigner `portrait: 'portrait.jpg'` dans `src/data/profile.ts`.
- Les images sont automatiquement redimensionnées et converties au build.
